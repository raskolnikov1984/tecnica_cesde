# Proyecto Integrador

## Objetivo

Concretar un proyecto aplicando los conocimientos impartidos a lo largo del curso, con la finalidad de agregarlo a sus portafolios personales.

## Evidencias de producto &mdash; Tercer momento

### Estructura HTML y CSS

Presentar las siete (7) p&aacute;ginas que se solicitan del proyecto, se debe entregar HTML y CSS. Las p&aacute;ginas que se solicitan son las siguientes:

1. **P&aacute;gina de inicio** &mdash; Presentaci&oacute;n de la empresa.
2. **P&aacute;gina de Servicios** &mdash; Servicios o productos que realice la empresa.
3. **P&aacute;gina CRUD** &mdash; Operaciones Crear, Leer, Actualizar, Borrar. Se refiere a las operaciones b&aacute;sicas que se realizan sobre los datos en una base de datos o sistema de informaci&oacute;n. Se crea un formulario implementando una de las tablas del ejercicio pr&aacute;ctico que tienen con la asignatura de base de datos.
4. **P&aacute;gina de Base de Datos** &mdash; Modelo entidad-relaci&oacute;n realizado en BD y alg&uacute;n script con la creaci&oacute;n de la base de datos o consultas.
5. **P&aacute;gina de L&oacute;gica** &mdash; Ejercicio b&aacute;sico de l&oacute;gica de programaci&oacute;n.
6. **P&aacute;gina de Contacto** &mdash; Formulario de contacto.
7. **P&aacute;gina del Equipo** &mdash; Presentaci&oacute;n de los integrantes del equipo.

### Requisitos comunes

Todas las p&aacute;ginas deben tener:

- **Encabezado (header)** con el logo de la empresa elegida.
- **Barra de navegaci&oacute;n**.
- **Banner principal** con una imagen y un eslogan atractivo.
- **Pie de p&aacute;gina (footer)** con enlaces a redes sociales y datos de contacto.
- La p&aacute;gina de contactos se debe incluir en el proyecto.
- Se debe presentar el **certificado de realizaci&oacute;n del curso de GITHUB** como nota de desempe&ntilde;o.
- Se entregar&aacute; el proyecto completamente (m&iacute;nimo siete p&aacute;ginas).
- Desplegar la soluci&oacute;n utilizando [GitHub](https://github.com/) (todos los estudiantes deben tener el proyecto en GitHub).
- Todas las im&aacute;genes deber&aacute;n incluir atributo `alt`.
- El c&oacute;digo debe ser legible y ordenado.

### Dise&ntilde;o Responsivo

Haz que tu p&aacute;gina web sea adaptable a diferentes tama&ntilde;os de pantalla utilizando **media queries** en tu archivo CSS. Aseg&uacute;rate de que el dise&ntilde;o se vea bien tanto en dispositivos m&oacute;viles como en computadoras de escritorio.

### Interactividad

Haz que los botones de navegaci&oacute;n y enlaces sean interactivos mediante cambios de estilo al pasar el rat&oacute;n por encima (**hover**). Agrega efectos de transici&oacute;n suaves para mejorar la experiencia del usuario al navegar por el sitio.

### Compatibilidad

Realiza pruebas exhaustivas en diferentes navegadores y dispositivos para garantizar la compatibilidad y funcionalidad del sitio en todos ellos.
