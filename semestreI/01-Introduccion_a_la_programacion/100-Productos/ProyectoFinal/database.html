SQL Scripts

Database creation and CRUD queries

CREATE TABLE 
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    phone VARCHAR(20) NOT NULL,
    address TEXT,
    created_at DATE DEFAULT CURRENT_DATE
);
INSERT 
INSERT INTO users (name, email, phone, address)
VALUES (
    'John Doe',
    'john.doe@email.com',
    '+1234567890',
    '123 Main St, City'
);
SELECT 
-- Get all users
SELECT * FROM users;

-- Get specific user by ID
SELECT name, email, phone
FROM users
WHERE id = 1;

-- Count total users
SELECT COUNT(*) AS total_users
FROM users;
UPDATE 
UPDATE users
SET
    name = 'Jane Doe',
    email = 'jane.doe@email.com',
    phone = '+0987654321',
    address = '456 Oak Ave, City'
WHERE id = 1;
DELETE 
-- Delete a specific user
DELETE FROM users
WHERE id = 1;

-- Delete all users (use with caution)
-- DELETE FROM users;
Advanced Queries 
-- Search users by name
SELECT * FROM users
WHERE name LIKE '%Alejandro%';

-- Users registered this month
SELECT * FROM users
WHERE MONTH(created_at) = MONTH(CURRENT_DATE)
  AND YEAR(created_at) = YEAR(CURRENT_DATE);
About This Model

The users table is the foundation for the CRUD operations on the CRUD page. The table stores basic user information including personal details and a timestamp for when each record was created. The id column serves as the primary key and auto-increments with each new record.

This design follows normalization principles to ensure data integrity and avoid redundancy. The JavaScript CRUD implementation on the previous page mirrors these SQL operations using localStorage for client-side persistence.
