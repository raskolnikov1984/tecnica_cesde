PROYECTO INTEGRADOR
Objetivo
Concretar un proyecto aplicando los conocimientos impartidos a lo largo del curso, con la finalidad
de agregarlo a sus porfolios personales.
Enunciado
En equipos de trabajo conformado de manera individual o hasta por tres personas, desarrollar un
sitio web con siete páginas como mínimo, para una organización, emprendimiento, empresa
(actividad a elección del estudiante) que cumpla, mínimamente con los siguientes requisitos:
Evidencias de producto tercer momento
Estructura HTML y CSS:
Presentar las siete (7) páginas que se solicitan del proyecto, se debe entregar HTLM y CSS.
Las páginas que se solicitan son las siguientes:

1. Página de inicio o presentación de la empresa
2. Página con los Servicios o productos que realice la empresa
3. Página con las operaciones CRUD (Crear, Leer, Actualizar, Borrar) se refiere a las
   operaciones básicas que se realizan sobre los datos en una base de datos o sistema de
   información. Se crea un formulario implementado una de las tablas del ejercicio práctico
   que tienen con la asignatura de base de datos
4. Página donde se muestre el modelo entidad relación realizado en BD y algún script con la
   creación de la base de datos o consultas.
5. Página con un ejercicio básico de lógica de programación
6. Página de contactos.
7. página con la presentación de los integrantes del equipo
   Todas las páginas deben tener
   • Encabezado (header) con el logo de la empresa elegida
   • Barra de navegación
   • Banner principal con una imagen y un eslogan atractivo
   • Pie de página (footer) con enlaces a redes sociales y datos de contacto
   • La página de contactos se debe incluir en el proyecto
   • Se debe presentar el certificado de realización del curso de GITHUB como nota de desempeño.
   • Se entregará el proyecto completamente (mínimo siete páginas). Desplegar la solución
   utilizando https://github.com/ (todos los estudiantes deben tener el proyecto en github.
   • Todas las imágenes deberán incluir Alt
   • El código debe ser legible y ordenado.
   Diseño Responsivo: haz que tu página web sea adaptable a diferentes tamaños de pantalla
   utilizando media queries en tu archivo CSS.
   Asegúrate de que el diseño se vea bien tanto en dispositivos móviles como en computadoras de
   escritorio.
   Haz que los botones de navegación y enlaces sean interactivos mediante cambios de estilo al pasar
   el ratón por encima. Agrega efectos de transición suaves para mejorar la experiencia del usuario al
   navegar por el sitio. Realiza pruebas exhaustivas en diferentes navegadores y dispositivos para
   garantizar la compatibilidad y funcionalidad del sitio en todos ellos. Este proyecto proporciona una
   excelente oportunidad para mostrar tus habilidades y experiencia en desarrollo web, así como
   para crear una presencia en línea profesional. Siéntete libre de personalizar y expandir el proyecto
   según tus intereses y necesidades. ¡Espero que disfrutes creando tu portafolio personal!
