Programming logic exercise

Generate the Fibonacci sequence up to n terms and explore the classic recursive algorithm.

Fibonacci Generator

Enter a non-negative integer (n) to generate the Fibonacci sequence up to F(n).

F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)

How It Works

Understanding the Fibonacci algorithm

Mathematical Definition

The Fibonacci sequence is defined by the recurrence relation: 

F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)  // for n > 1

Each number is the sum of the two preceding ones, starting from 0 and 1.

Java Implementation 
public static int[] fibonacci(int n) {
    int[] sequence = new int[n + 1];
    int a = 0, b = 1;

    for (int i = 0; i <= n; i++) {
        sequence[i] = a;
        int temp = a + b;
        a = b;
        b = temp;
    }

    return sequence;
}

This iterative approach runs in O(n) time and uses O(n) space.

Applications

The Fibonacci sequence appears in many areas:

  • Nature - Flower petals, seed heads, and spiral shells follow Fibonacci patterns.
  • Computer Science - Fibonacci search, heap data structures, and recursion examples.
  • Finance - Fibonacci retracement is used in technical analysis.
  • Algorithms - Classic example for teaching recursion and dynamic programming.
