## SQL vs NoSQL**

**Cuándo usar SQL: Escalamiento Vertical**

- Datos estructurados: Cuando tus datos tienen un esquema fijo y bien definido.
- Relaciones complejas: Si tus datos tienen muchas relaciones entre sí (por ejemplo, clientes, pedidos, productos).
- Transacciones ACID: Cuando necesitas garantías de Atomicidad, Consistencia, Aislamiento y Durabilidad.
- Consultas complejas: Si necesitas realizar consultas complejas que involucren múltiples tablas.
- Aplicaciones tradicionales: Como sistemas de gestión empresarial, contabilidad, recursos humanos.

**Cuándo usar NoSQL: Escalamiento Horizontal**

- Datos no estructurados o semiestructurados: Cuando el esquema de tus datos puede variar o no está bien definido.
- Gran volumen de datos: Si manejas cantidades masivas de datos y necesitas escalar horizontalmente.
- Alta velocidad de escritura/lectura: Para aplicaciones que requieren operaciones de lectura/escritura muy rápidas.
- Flexibilidad en el esquema: Cuando necesitas añadir nuevos campos o tipos de datos frecuentemente.
- Aplicaciones en tiempo real: Como redes sociales, IoT, análisis en tiempo real.
- Desarrollo ágil: Si necesitas iterar rápidamente y cambiar la estructura de datos con frecuencia.

**Ejemplos específicos:**

- SQL: Sistemas bancarios, comercio electrónico tradicional, sistemas de reservas.
- NoSQL: Redes sociales, aplicaciones móviles, juegos online, sistemas de recomendación.
